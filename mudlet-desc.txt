Mindlink: Telepathic Communication Ledger (v1.2.6)

Mindlink is a modern, lightweight message catcher for Achaea, inspired by predecessors like YATCO but simplified, streamlined, and with zero dependencies. It captures your game's chat channels, tells, and emotes, organizing them into a clean, tabbed Geyser interface so you never lose a message to combat or travel spam again.

Features include an interactive in-game dashboard, automatic profile saving, advanced channel filtering, and automated RP logging.

Type 'mindlink help' to get started.
